DEPARTMENT OVERVIEW

Activities & Skills

Discover the flagship activities and technical competencies developed in each department, presented in a clear layout for every device.

Software Engineering

Software Engineering focuses on the development of applications and modern digital systems.

  • Mobile and web application development
  • User interface and experience design
  • School information system development

Computer & Network Engineering

Computer & Network Engineering specializes in infrastructure setup, network installation, and IT hardware maintenance.

  • LAN/WLAN installation and configuration
  • Computer hardware repair
  • Local server security and management

Automotive Engineering

Automotive Engineering equips students with service and maintenance skills for modern vehicles.

  • Engine and vehicle electrical system service
  • Fault diagnosis and quality control
  • Technology-based vehicle maintenance

Electrical

Electrical Engineering teaches wiring, control systems, and power distribution fundamentals used around the world.

  • Residential and industrial wiring
  • Motor control and automation
  • Renewable energy systems integration

Mechatronics

Mechatronics blends mechanics, electronics, and programming for modern automated systems and robotics.

  • Sensor and actuator integration
  • Basic robotics and control logic
  • Smart device prototyping

Automation

Automation offers practical skills for industrial controls, robotics, and smart manufacturing systems.

  • Programmable logic controllers
  • Process automation and monitoring
  • Robotic system basics
